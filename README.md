# gv-unpack

Распаковщик контейнеров GamesVoice `GVARC` (`*.gv`) на Python. Позволяет достать содержимое озвучки (например, русской озвучки GTA Vice City: Definitive Edition) без запуска установщика `.exe`.

Проверено на `Definitive.gv` из GTAVC_GV_Rus v1.2: внутри лежат `pakchunk0-WindowsNoEditor_9-GV-RU_P.pak` и логотип-ролик `GamesVoice_Logo_Snow.mp4`.

> Репозиторий содержит только инструмент. Сами `.gv`-файлы и озвучка принадлежат их авторам и сюда не включены.

## Использование

Нужен Python 3.8+.

```
pip install lz4        # необязательно, но в разы быстрее
python gv_unpack.py --list [файл.gv]   # показать содержимое
python gv_unpack.py [файл.gv]          # распаковать (по умолчанию Definitive.gv)
```

Результат появится в папке `extracted/` рядом с `.gv`, с теми же путями, что и в игре. После распаковки скрипт проверяет ролик (`ftyp`) и футер UE у `.pak`.

Без модуля `lz4` работает запасной декодер на чистом Python (~10 МБ/с).

## Установка озвучки GTA VC: DE вручную

1. Сделай копию своей папки `Gameface\Content\Paks`.
2. Скопируй `extracted\Gameface\Content\Paks\*.pak` в `...\Gameface\Content\Paks\`.
3. (Необязательно) `extracted\Gameface\Content\Movies\GV\*.mp4` в `...\Gameface\Content\Movies\GV\`.
4. Запусти игру.

Озвучка собрана под конкретную версию игры; после обновления игры файл может устареть.

## Формат GVARC

Все числа little-endian.

| Смещение | Поле |
|---|---|
| `0x00` | `GVARC` |
| `0x10` | u32: число файлов |
| `0x14` | u32: начало таблицы файлов (36) |
| `0x18` | u32: размер таблицы. Данные начинаются с `0x14 + 0x18` |
| `0x23` | u8: ключ XOR для данных |

Таблица с `0x24`, на каждый файл:

```
u32  длина имени
...  имя (путь через '\')
u32  0
u32  число чанков N
u64  полный размер файла
N *  { u32 размер распакованный, u32 размер упакованный, u64 смещение в .gv }
```

Каждый чанк это блок LZ4 (raw block, без frame-заголовка), все байты которого XOR-нуты ключом из `0x23`. После чанков в файле идёт 4 нулевых байта. Распакованные чанки склеиваются по порядку.

Формат выяснен по анализу заголовка и проверен: цепочка смещений сходится, а после XOR данные начинаются с корректного токена LZ4 и заголовка `ftyp` у mp4.
